# 🚗 Rydex - Vehicle Booking Website

---

## ✨ Features

- User Authentication (JWT)
- Browse vehicles (Bike, Car, Premium)
- Real-time booking system
- Booking history dashboard
- Responsive UI

---

## 🛠️ Tech Stack

- Frontend: React.js, CSS
- Backend: Node.js, Express.js
- Database: MongoDB
